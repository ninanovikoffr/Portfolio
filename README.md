# Portfolio

Portfólio de UI/UX design construído com React, Vite e Framer Motion.

## Começar

```bash
npm install
npm run dev
```

Depois, abra o endereço exibido pelo Vite no terminal.

## Scripts

- `npm run dev` inicia o servidor de desenvolvimento.
- `npm run build` cria a versão de produção.
- `npm run preview` visualiza a versão de produção localmente.

As animações principais estão em `src/main.jsx`, usando `motion`, e os estilos em `src/styles.css`.

Os arquivos estáticos devem ficar em `public/assets/`. Por exemplo: `public/assets/nextpath.png`.
